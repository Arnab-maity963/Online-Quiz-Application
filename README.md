# Online-Quiz-Application


## About the Project

The **Online Quiz Application** is a full-stack web application developed using React and modern web technologies. It allows users to participate in online quizzes, answer multiple-choice questions (MCQs), and view their results instantly.

The main objective of this project is to provide an interactive platform for students to test their knowledge, improve learning, and evaluate their performance.

## Features

- User Registration and Login
- Secure User Authentication
- Interactive Quiz Interface
- Multiple Choice Questions (MCQs)
- Automatic Score Calculation
- Instant Result Display
- Database Integration
- Responsive User Interface
- Real-Time Quiz Evaluation

## Application Workflow

1. Users register or log in.
2. Users access the quiz dashboard.
3. Users select an available quiz.
4. Questions and multiple-choice options are displayed.
5. Users submit their answers.
6. The backend evaluates the answers.
7. The application displays the final score and result.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Online-Quiz-Application.git
```

### 2. Navigate to the Project

```bash
cd Online-Quiz-Application
```

### 3. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

### 4. Setup Backend

Open another terminal:

bash
cd backend
npm install
npm run dev


### 5. Configure Environment Variables

Create a `.env` file inside the backend directory:

env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
